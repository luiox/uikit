# libant-qt 代码文档

## 项目定位

`libant-qt` 是当前仓库里的 Qt Widgets 组件库，负责提供：

- 通用控件与页面容器
- 主题、图标、弹层、遮罩等基础设施
- 给 `libant-qt-demo` 提供可复用的演示组件

本库当前已经完成两类收敛：

1. 构建入口统一到 `xmake`
2. 公共头文件逐步统一到 `ant` 命名空间（当前通过兼容导出保证老代码不被打断）

## 命名空间现状

当前库处于“迁移进行中”状态：

- 一部分核心类已经直接定义在 `namespace ant` 内
- 其余公开头文件已经补齐 `namespace ant { using ::TypeName; }` 兼容导出

这意味着现在两种写法都可用：

```cpp
AntButton* btn = new AntButton("确定", 12, parent);
ant::AntButton* btn2 = new ant::AntButton("确定", 12, parent);
```

推荐后续新增代码统一使用 `ant::` 前缀，逐步减少全局命名空间依赖。

## 推荐使用入口

### 1. 主题与图标

优先通过：

- `ant::DesignSystem::instance()`
- `ant::IconProvider`

不要在业务层散落颜色常量或直接拼资源路径。

### 2. 组合控件

若只是搭页面，优先复用现有组件：

- 输入：`AntInput` / `MaterialLineEdit`
- 按钮：`AntButton`
- 标签页：`MaterialTabWidget` / `AntTabWidget`
- 列表表格：`AntTreeView` / `AntProfileTable` / `AntChatListView`
- 空态与骨架：`NoDataWidget` / `SkeletonWidget`

### 3. 弹层与浮层

优先使用控制器类管理显示与动画：

- `DialogViewController`
- `PopupViewController`
- `BubbleViewController`
- `AntTooltipManager`
