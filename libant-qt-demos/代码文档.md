# libant-qt-demos 代码文档

## 工程目标

`libant-qt-demos` 用于给 `libant-qt` 提供可直接运行的分类化示例。

它解决两个问题：

1. `libant-qt-demo` 更偏场景装配，适合展示完整交互链路。
2. 开发者在查某个控件或某类能力时，需要一个更像“示例手册”的入口。

## 页面说明

### 1. CoreCapabilitiesPage

覆盖 `src/core/` 的主要能力：

- `DesignSystem`：展示当前主题色板，并允许切换明暗模式
- `IconProvider`：统一从角色枚举获取图标预览
- `GaussianBlur`：基于代码生成的图片做模糊处理
- `StyleSheet`：预览典型样式函数输出和按钮效果

### 2. CommonControlsPage

覆盖常见输入和选择控件：

- `AntButton`
- `AntToggleButton`
- `AntRadioButton`
- `Win11CheckButton`
- `MaterialLineEdit`
- `AntInput`
- `AntComboBox`
- `AntNumberInput`
- `AntDoubleNumberInput`
- `AntSlider`

并补了一个“新建任务”的组合表单示例，避免只停留在单控件孤立展示。

### 3. FeedbackShowcasePage

覆盖状态反馈相关组件：

- `MaterialProgressBar`
- `MaterialSpinner`
- `AntMessageManager`
- `BadgeWidget`
- `SkeletonWidget`
- `NoDataWidget`

### 4. DisplayShowcasePage

覆盖展示类与工具类组件：

- `GlassWidget`
- `LogoWidget`
- `AnimatedNumber`
- `CardWidget`
- `TagWidget`
- `FlowLayout`
- `QrCodeWidget`
- `PaginationWidget`

## 设计原则

- 以“开发参考”优先，而不是只追求完整页面观感
- 每个页面只展示一到两类职责接近的组件
- 尽量避免外部资源强依赖，核心示例优先使用代码生成内容
- 对需要主题联动的示例，直接通过 `DesignSystem` 广播刷新
