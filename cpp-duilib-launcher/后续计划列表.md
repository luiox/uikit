# cpp-duilib-launcher 后续计划列表

## P0：优先补齐用户最容易直接碰到的缺口

### 1. 搜索命令解析

目标：让搜索框不仅能过滤，还能执行 VB6 风格命令。

建议拆分：

1. 在 `SearchController` 增加命令识别层
2. 支持精确命令：
   - `cmd`
   - `setting`
   - `shutdown`
   - `reboot`
   - `logoff`
   - `screenoff`
3. 支持“百度 + 关键词”模式
4. 保持原有名称过滤不回退

### 2. 项目编辑窗 MVP

目标：替代当前“重新选 exe”的简化编辑流程。

最小版本字段：

- 标题
- 路径
- 参数
- 图标位置

优先建议：

- 先用简化 DuiLib 自绘窗完成 MVP
- 先不追求完全复刻 VB6 布局，只保证字段完整

### 3. 设置窗 MVP

目标：先把关键配置收口到一个统一入口。

建议首批字段：

- 热键
- 启动后隐藏/执行后隐藏
- 默认窗口宽高
- 分组栏宽度

### 4. 主菜单补全

当前菜单按钮已存在，适合继续补执行逻辑。

建议顺序：

1. `Sort By Name`
2. `Import Data`
3. `Export Data`
4. `Settings`
5. 再补 VB6 的特殊“新建项目”子项
