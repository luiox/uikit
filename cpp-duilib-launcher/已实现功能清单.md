# cpp-duilib-launcher 已实现功能清单

> 依据：`VB6_UI参数与需求分析.md`、`C++实现_vs_VB6标准_逐项差异表.md`，并结合 `src/` 实际代码核对。

## 一、窗口与视觉基线

已实现：

- 主窗口标题为 `Poner`（`ui_builder.cpp`）
- 去除系统标题栏，采用无边框窗口（`app_window.cpp::OnCreate`）
- 顶栏背景使用 `0xFFE6E6E6`，与 VB6 灰阶基线一致（`ui_builder.cpp`）
- 主文本主色使用 `0xFF5A5A5A`（`ui_builder.cpp` / 列表渲染）
- 搜索条背景已为 `0xFFD2D2D2`（`ui_builder.cpp`）

## 二、主界面基础结构

已实现：

- 顶栏包含搜索、菜单、关闭三个入口（`ui_builder.cpp`）
- 左侧分组区 + 中间分隔条 + 右侧项目区布局（`ui_builder.cpp`）
- 底部状态栏（`ui_builder.cpp`）
- 分组新增/重命名弹层（`group_dialog`，见 `ui_builder.cpp` + `dialog_manager.cpp`）

## 三、分组能力

已实现：

- 分组渲染与排序显示（`list_controller.cpp::RenderGroups`）
- 分组选择切换（`SelectGroupByIndex`）
- 分组新增（`DialogManager::ConfirmGroupDialog` -> `backend_.AddGroup`）
- 分组重命名（`DialogManager::ConfirmGroupDialog` -> `backend_.RenameGroup`）
- 分组删除（`DeleteActiveGroup`）
- 删除分组时把项目迁移到其他分组（`DeleteActiveGroup` + `backend_.DeleteGroup`）
- 分组拖拽排序（`app_window_interaction.cpp::CommitListDragReorder` -> `backend_.ReorderGroup`）

## 四、项目能力

已实现：

- 项目列表渲染（普通模式 / 搜索模式）（`list_controller.cpp::RenderItems`）
- 双击或激活项目启动（`Notify` -> `LaunchSelectedItem`）
- 项目删除（`DeleteSelectedItem` -> `backend_.DeleteItem`）
- 项目新增（当前为选取可执行文件的轻量流程，`AddItemFromFile`）
- 项目编辑（当前也是基于重新选择文件的轻量流程，`EditSelectedItem`）
- 项目移动到其他分组（`MoveSelectedItemToGroup` -> `backend_.MoveItem`）
- 项目拖拽重排（`CommitListDragReorder` -> `backend_.ReorderItemInGroup`）

## 五、项目右键菜单扩展命令

已实现：

- 管理员运行（`RunSelectedItemAsAdmin`）
- 打开文件位置（`OpenSelectedItemFolder`）
- 打开资源管理器属性/菜单入口（当前实现为 `properties`，见 `ShowSelectedItemShellMenu`）
- 复制完整路径（`CopySelectedItemPath`）

## 六、搜索与快捷交互

已实现：

- 搜索模式切换（`SearchController::ToggleSearchMode`）
- 搜索输入实时刷新项目列表（`HandleInputChanged` -> `RenderItems`）
- 搜索模式下跨分组显示结果，并在项目名后追加 `[组名]`（`RenderItems`）

## 七、数据与兼容层

已实现：

- 从旧版 `Data.json` 导入数据（`backend.cpp::Load`）
- 从 `Poner.cfg` 导入部分设置（`ParsePonerCfg`）
- 新数据持久化到 `launcher.v2.json`
- 设置持久化到 `nassistant.settings.json`
- 损坏 / 版本不兼容 JSON 的自动备份与恢复（`BackupCorruptedJson`）
- 拖拽导入外部路径（`HandleFileDrop` -> `CreateItemsFromDroppedPaths`）
- `.lnk` 解析支持（后端实现链已存在）

## 八、窗口状态与交互细节

已实现：

- 分栏宽度拖动调整（`app_window_interaction.cpp`）
- 窗口位置/大小/最大化状态保存与恢复（`SaveUiState` / `RestoreUiState`）
- 组/项目拖拽操作的命中测试与节流处理（`app_window_interaction.cpp`）

## 九、自动化验证基础

已实现：

- `backend_tests.cpp` 已覆盖：
  - 旧版 `Data.json` 导入
  - 分组与项目 CRUD
  - 项目跨组移动
  - 不兼容版本恢复
  - 损坏 JSON 恢复

## 十、结论

当前 `cpp-duilib-launcher` 已经不是“纯骨架”状态，而是已经具备：

- 可运行主窗口
- 分组/项目核心 CRUD
- 启动与拖拽导入
- 部分 VB6 对齐的菜单与右键能力
- 基础数据兼容与测试

它已经能支撑日常使用的基础路径，但离 VB6 版本的完整功能仍有明显差距，尤其在主菜单完整度、搜索命令语义、编辑窗和设置窗这几块。
