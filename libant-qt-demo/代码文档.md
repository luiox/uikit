# libant-qt-demo 代码文档

## 项目定位

`libant-qt-demo` 是 `libant-qt` 的独立演示工程，用来承担三件事：

- 组件组合展示
- 资源与主题回退验证
- 运行时字体、布局、交互冒烟测试

---

## 主要文件

### 1. 入口与全局初始化

- `main.cpp`
  - 查找项目根目录
  - 加载应用内字体资源
  - 设置全局应用字体和 Han 脚本回退链
  - 创建主窗口 `ant::LibAntQtDemoWindow`

当前字体策略：

- 优先使用打包进资源的 `NotoSansSC`
- 再回退到 `Microsoft YaHei UI / Microsoft YaHei / Segoe UI / Arial`

这能减少 Windows 下直接落到异常字体或位图字体时出现的乱码/崩溃风险。

### 2. 主窗口

- `LibAntQtDemoWindow.h/.cpp`
  - 整个 demo 的壳层窗口
  - 负责导航栏、标题栏、内容区、主题切换、遮罩与通知管理器初始化
  - 内部装配四个页面：
    - `HomePage`
    - `FunctionPage`
    - `SettingsPage`
    - `AboutPage`

### 3. 页面说明

#### `HomePage`

- 轻量首页
- 负责展示 demo 的定位与说明
- 当前已改成中文文案，便于直接观察中文字体渲染效果

#### `FunctionPage`

这是核心展示页，集中演示了 `libant-qt` 的主要组件能力，包括：

- 标签页与切换容器
- 滚动区域
- 轮播图
- 开关、进度条、圆形加载
- 单选按钮、滑动条、数字动画
- 骨架屏
- 通知框
- 数字输入 / 小数输入
- 下拉框
- 标签、卡片、二维码
- 流式布局
- 抽屉
- 徽标
- 聊天列表
- 表格
- 树视图

它是验证 `libant-qt` 是否还能正常工作的最佳入口。

#### `SettingsPage`

- 简单占位页
- 当前主要用于验证大字号中文标题展示

#### `AboutPage`

- 简单占位页
- 当前主要用于验证大字号中文标题展示

## 运行链路

1. `main.cpp` 初始化字体与工作目录
2. 创建 `LibAntQtDemoWindow`
3. 主窗口初始化设计系统、主题、遮罩、通知器
4. 装配四个页面
5. 默认进入首页，其他页面通过左侧导航切换

---

## 当前用途建议

这个工程最适合承担：

- 新控件开发后的组合验证
- 字体、图标、主题切换的运行时检查
- 对 `libant-qt` 的视觉回归测试

不建议继续把大量通用逻辑堆在 demo 页面里；通用能力应优先回收到 `libant-qt`。

---

## 构建与验证

仓库根目录：

```bash
xmake build -r libant_qt_demo
```

运行：

```bash
xmake run libant_qt_demo
```

如果主要验证字体问题，建议重点看：

- 首页中文标题与描述
- 设置页 / 关于页的大字号中文标题
- 功能页中的中文标签、按钮、描述文字
